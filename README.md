# CIM Course Overview

The California International Marathon (Folsom to the State Capitol in Sacramento) as a rotatable 3D terrain map.

- Every mile is a labelled white dot; every 5K is a large orange tag.
- Drag the elevation profile, or use the slider, to move along the course. Grade and elevation are read out at each point.
- Numbered purple badges mark hills and features, each with a short note. Click one, or any note in the list, to jump there.
- **Fly over the course** rides a camera along the route at 0.5×–4× speed.
- Drag to pan, right-drag (or Ctrl-drag) to rotate and tilt, scroll to zoom. Switch basemaps, toggle terrain, and color the route by elevation or grade.
- Link straight to a spot with `?mile=11.3`.

Built with React, Vite and [deck.gl](https://deck.gl), the same way as [kate-peaks](https://github.com/kstraneva/kate-peaks). Terrain is Mapzen/AWS terrain tiles; imagery from Esri, OpenTopoMap and OpenStreetMap (credited in the viewer). Only the area around the course is drawn.

## Develop
```
npm install
npm run dev
```

## Data
The course line comes from the 2025 CIM track published by [goandrace.com](https://www.goandrace.com/en/map/2025/california-international-marathon-2025-sacramento-course-map-1.php). This project is not affiliated with goandrace.com, the California International Marathon or the Sacramento Running Association.

`src/data/cim.json` is generated by `npm run build-course` from a GPX of the course placed at `raw/cim-2025.gpx` (not committed). The script resamples the track every 25 m, rescales its length to the official 42.195 km, and takes elevation from the same terrain tiles the 3D view uses.

Gain and descent are computed from that elevation profile (smoothed, 3 m threshold), so they will differ from published figures. The hill notes in `src/notes.js` are written from the same profile.

## Deploy
The included GitHub Actions workflow builds and publishes to GitHub Pages on every push to `main`. Enable it once under **Settings → Pages → Source: GitHub Actions**.
